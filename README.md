# FH-CRM

CRM система для управления фитнес-центром.

## Функциональность

- 📊 Дашборд с ключевыми показателями
- 👥 Управление клиентами (CRUD)
- 🏋️ Управление тренерами (CRUD)
- 💳 Управление абонементами (CRUD)
- 📅 Управление расписанием (CRUD)
- 💰 Управление платежами (CRUD)
- 📈 Отчеты и аналитика

## Технологии

- React 18
- Vite
- CSS Modules
- REST API

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build

# Превью сборки
npm run preview
